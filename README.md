# The Great Lakescape Lodge

Tutorial 2 — Case Problem 4 (Getting Started with CSS3)

158.256 Web Application Design — Lab 2 submission.

A single-page website for *The Great Lakescape Lodge* (Baileys Harbor, Wisconsin),
demonstrating CSS3 colour scheme & typography techniques:

- `@charset` declaration and web fonts (`@font-face`, `.woff` + `.ttf`)
- Background/text colours using both colour values and colour names
- Semi-transparent colours (`rgba()`)
- Nested / child / id selectors
- List & list-marker styling
- Pseudo-elements (`::before`, `::after`, `::marker`) and pseudo-classes (`:hover`, `:focus`, `:first-child`)
- Padding & margin control
- Generated content (`content:`)
- Flexbox (footer) and Grid (header nav) layouts
